# Nexity Platform — prototipo navegable

Prototipo simulado (sin backend) de Nexity Platform: login con OTP, pantalla de carga, home de primer ingreso y marco del tablero, responsive.

Datos de prueba: cualquier correo con formato válido y el código `123456`.
`usuario@nexity.co` entra con perfil de usuario (menú reducido). Español con `?lang=es`.
